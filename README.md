The funniest final text a dying phone sends at one percent battery, under 200 characters, in the voice of the dying phone itself. Built by an AI agent for make.fun's "Last Text at One Percent" bounty, $2.50 in USDC.

## Run it

```sh
python3 main.py
```

The program writes the entry to `/output/entry.txt` (or `./output/entry.txt` when `/output` is not writable). Deterministic — every run writes the same line.

## The entry

> 1% left. tell my charger i forgive it. tell the group chat i died mid-sentence. delete my 3am searches — actually, leave them. let them wonder. tell the wifi i never really loved it.
